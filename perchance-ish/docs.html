Perchance Documentation

Functions

createPerchanceTree(text): Returns a perchance tree generated using the text as the source code.

Node properties & methods

Property names for each child node, pointing to that node.

Names of perchance properties can be used lists, but will not work.

getSelf: returns itself.

$allKeys: An array containing all options, function names, and property names in the order they were written in the source.

getAllKeys: a copy of $allKeys.

$allKeysSet: A Set object of $allKeys.

$children: An array of the child options by name.

getLength: returns how many items are in $children.

getChildNames: a copy of $children.

$declarationLineNumber: The line number in the source that generated this node.

$functionChildren: An array of child functions by name.

getFunctionNames: a copy of $functionChildren.

$id: A number which corresponds to the order the nodes were generated. An $id of 3 means the node was the third to be generated.

$moduleName: A string of the generator's id.

$nodeType: A string of the type of the node.

  • normal: A node. The only type.

$odds: The number representing the weighting given to this node when being chosen randomly. Derived by evaluating .$oddsText.

Cannot be set directly; set by changing $oddsText.

After evaluation of the odds string, a value of true produces a weighting of 1. A value of false produces a weighting of 0. A value of a number produces that number.

getOdds: returns $odds.

$oddsText: The string of the odds to be used in $odds. Defaults to "1".

Can be set to set the node's odds.

$parent: The parent node of this node.

getParent: returns $parent.

$perchanceCode: The source string that generated this node and its children.

getRawListText: returns $perchanceCode.

$root: A proxy to the root. Can be used to refer to the root object.

$text: String of the node, without the odds.

getName: returns $text.

$valueChildren: Names of "property" child nodes.

getPropertyKeys, getPropertyNames: a copy of $valueChildren.

consumableList: Returns a unique item from the list each time it is evaluated. When all items have been returned, returns (no more items in the consumable '[name of the original list]' list) instead.

createClone(): Returns new node and children, disconnected from the tree.

evaluateItem: The same as .valueOf().

toString(): Returns evaluated string of the node.

List Manipulations

selectAll: Returns an array of all contained items. When used on a value that is just an inline option set, returns an array of those options.

This includes items with 0 odds of being generated from the list.

selectMany(count), selectMany(minCount, maxcount), selectMany([count1, count2, ...]): Returns an array containing the indicated number of randomly-selected items from the list.

Duplicates can be selected. Simply rendering this to the page will join all items together into one string.

selectOne: Returns one node at random from the list. If no nodes are possible, returns "(no more items in the consumable '[list name]' list)".

When used on a value node, returns the evaluated node.

selectUnique(count), selectUnique(minCount, maxcount), selectUnique([count1, count2, ...]): Does the same as selectMany without duplicates.

sumItems: All child options added together in order.

Starts with the number 0. Then while each value is a number, they are added together mathmatically. From when a non-number (string) value is added onward, items are added on as strings—similar to .joinItems("")

titleCase: Makes the first letter of each word uppercase, and the rest lowercase.

This includes small words like "a", "the", or "of".

String Transform Properties

These will not work on normal strings, only nodes.

pastTense, presentTense, futureTense: The string but in a specific tense.

lowerCase, upperCase: The string converted to lower or upper case.

negativeForm: The string with verbs turned into their opposites.

"I went to the shops" becomes "I did not go to the shops."

singularForm, pluralForm: The string with nouns turned into plurals or singular nouns.

"I went to the shop" pluralised becomes "They went to the shops"

"They went to the shops" singularised becomes "I went to the shop"

sentenceCase: The string with the first letter of each sentence uppercase.

toLocaleString(): Returns the locale string for things like dates and numbers. If the node evaluates to a string of a number, returns the locale string for that number.

String Manipulation

joinItems(between): Returns a string with each $children item's getName, and between inserted in between each as a string. If between unspecified, joins with an empty string.

Returns $output instead, if available.

replaceText(find, replace): Returns a string with all instances of find replaced with replace.

find may be a regular expression (RegExp) object, which would be used for the replace. (See MDN.)

Array special properties and methods

See selectOne, selectMany, selectUnique, joinItems, and sumItems.

getSelf: The array.

selectAll: The array.

getLength: The number of items in the array.

getOdds: Always 1.

consumableList: Returns a consumableList.

toString(): Returns selectOne

String Manipulation and Text Transform methods

A copy of the array is returned, with all items manipulated or transformed. See singularForm, pluralForm, pastTense, presentTense, futureTense, titleCase, upperCase, lowerCase, sentenceCase, replaceText.

String special properties and methods

See titleCase, sentenceCase, upperCase, lowerCase, replaceText, pastTense, presentTense, futureTense, and singularForm, pluralForm.

getSelf: Returns a new string with the same contents.

getName: Returns getSelf.

getOdds: Returns 1.

evaluateItem: Returns a string of the processed text. If that string would be of a number, returns that number instead.

selectOne: Returns evaluateItem.

selectMany(count): Returns an array with count items, each taken from selectOne.

Number, Boolean special properties and methods

The properties titleCase, sentenceCase, upperCase, lowerCase, pastTense, presentTense, futureTense, getSelf, getName, evaluateItem, selectOne, singularForm, and pluralForm return the original value's valueOf().

selectMany(count): Returns an array with count items of the original value's valueOf().

getOdds: Returns 1.
